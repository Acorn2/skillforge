# 网页 GPT 参考效果分析

用户提供三张成品海报，分别为成品页、备料页、综合页。仅作为版式与风格目标，不作为菜名、日期和经营事实的证据。参考原图不打包进 Skill。

| 参考中的关键效果 | 现实现 |
|---|---|
| 醒目的白色手写机构名 | 每页从 brand.name 渲染，字号大于黄色条中的栏目 |
| 深绿植物背景与浅绿下部 | 内置植物背景，包含叶片、柔焦与纸面纹理 |
| 黄色笔刷、奶油白大圆角分区 | 脚本绘制固定比例分区和标题条 |
| 照片占满卡片、标签压底边 | 食物默认 cover，绿/橙胶囊加白边，限制文字侵入量 |
| 卡片双行短句与彩色小插画 | 从核实名称派生中性说明，透明装饰图不替代食物照片 |
| 综合两排四列、备料四列、成品 3+2 | 标准九图采用固定结构，汤品由 C 承载并记入清单 |
| 备料页下方两个信息区 | 「备料小记」和「让家长看见餐食日常」 |
| 底部图标式三列收尾 | 保留暖黄标签和绿色图标，文字只表达记录与分享 |

上一版偏差：完整显示优先和自由网格导致竖图缩进宽框，缺少手写字体、食材插画和背景质感。只检查文字不越界、文件有效，无法证明接近参考。现以卡片铺满率、指定行列、真实字体加载和逐页肉眼检查共同验收。

不照搬的文字：新鲜现切、自然成熟、每日现做、营养均衡、丰富膳食纤维、暖胃、孩子更爱吃等不能由照片证明。原料与成品不因上下排列就建立加工对应，红薯备料不推断为土豆丝原料。粉蒸肉的肉种未核实则不用猪插画；汤品不猜具体汤种。

视觉接近度来自布局、字体、装饰和原图构图。不得通过 AI 替换、重绘用户的食物来追求参考中的鲜亮菜色。完整规范见 [视觉规范](visual-guidelines.md)。
